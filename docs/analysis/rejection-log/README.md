# Аналіз логу відсіву вакансій / Rejection-log analysis

Серія аналізів логів, які пише [job-search pipeline](../../../README.md) при відсіві вакансій для ролі Junior Data / Product Analyst (remote, UA-ринок).

| Файл | Що всередині |
|---|---|
| [01_findings_03-09_oct.md](01_findings_03-09_oct.md) | Базовий зріз 03–09.10.2026 (до виправлень) |
| `02_changes.md` | _заплановано_: що змінено за результатами |
| `03_findings_after.md` | _заплановано_: той самий зріз після змін |

**Приватність.** У репозиторії лише агрегати (`data/*.csv`) та знеособлені приклади. Назви компаній, URL вакансій і персональні дані з логів не публікуються.

**Методика.** Логи з Google Drive (Sheets → CSV), об’єднання за нормалізованим URL (без query/fragment). Усі числа відтворюються з `data/`.
